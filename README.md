# MoyuPlus

> 在 VS Code 里安静地读完一本书，也认真地练好每一次输入。

MoyuPlus 是一款**离线优先的 VS Code 阅读与打字练习扩展**。它以本地 TXT、EPUB 2/3 为内容基础，将书架管理、章节阅读、沉浸式阅读与打字训练整合进编辑器，并始终把隐私、内容安全和阅读进度留在本地。

项目目前由两项核心能力组成：

| 模块 | 能力概览 |
| --- | --- |
| **MoyuPlus Reader** | TXT / EPUB 2/3 书架、章节目录、无滚动分页、阅读进度、内部链接与脚注导航、图片安全预览、沉浸阅读 |
| **MoyuPlus Typing** | TXT / EPUB / 粘贴文本练习、中文输入法支持、多种练习计划、实时统计、历史记录与错词强化 |

## 为什么选择 MoyuPlus

- **不打断工作流**：阅读与练习都发生在 VS Code 内，无需频繁切换应用。
- **真正离线优先**：本地书籍不上传，阅读过程不依赖网络服务。
- **不修改代码**：沉浸阅读只在编辑器中绘制内容，不插入、不保存，也不会让文档产生 dirty 状态。
- **认真对待 EPUB**：从容器、书目到正文和资源均经过独立解析与安全处理，而不是将出版物 HTML 原样注入页面。
- **阅读与练习互通**：Reader 书架中的 TXT、EPUB 可以直接成为打字素材，让“读过”自然延伸为“练过”。

## 阅读器

### 书架与分页阅读

在资源管理器中打开 **MoyuPlus Reader**，即可导入本地 TXT 或 EPUB。Reader 会保存书籍元数据与阅读位置，并在再次打开时恢复到上次章节和页内进度。

- 支持 TXT、EPUB 2 与 EPUB 3 混合书架。
- 支持章节目录、上一页 / 下一页、上一章 / 下一章。
- EPUB 目录 fragment、页码、脚注、尾注与返回链接使用统一的内部导航。
- “撤回阅读位置”可逐步返回本次阅读会话中的最近位置，最多保留 50 条记录。
- 正文根据可见区域的宽度和高度进行真实分页；长文本、`pre` 内容与宽表格会在页内安全折行，不以横向滚动或隐藏裁切制造“伪分页”。
- 阅读字号、字体、行高、页边距和主题可在 MoyuPlus 设置面板中调整。

### EPUB 解析：从出版物到安全、稳定的阅读内容

MoyuPlus 为 EPUB 建立了完整的本地解析链路：

```text
EPUB / ZIP
   ↓  容器与路径安全校验
META-INF/container.xml
   ↓
OPF：metadata · manifest · spine
   ↓
EPUB 3 Navigation / EPUB 2 NCX
   ↓
章节按需读取与语义清洗
   ↓
统一排版 · 内部导航 · 沉浸文本投影
```

解析过程重点处理以下内容：

- **书目信息与阅读顺序**：读取标题、作者、标识符、Manifest 与 Spine，按出版物声明的顺序组织章节。
- **EPUB 2/3 目录兼容**：优先解析 EPUB 3 Navigation Document；缺失时回退到 EPUB 2 NCX；仍无目录时根据 Spine 生成可用章节列表。
- **按需读取**：正文和图片只在实际访问时从压缩包读取，不将整本书解压到工作区，也不创建长期正文副本。
- **统一语义排版**：保留标题、段落、列表、引用、表格、代码、脚注等结构，移除出版物 CSS、内联样式、表现型 class 及固定尺寸，让不同来源的 EPUB 在窄侧栏中保持一致、可读。
- **内部目标映射**：同章与跨章链接会被转换为 Reader 内部目标；外部网页链接不产生网络跳转。
- **图片安全预览**：图片不会直接嵌入正文。点击“查看图片”后，MoyuPlus 才会校验 Manifest 声明和实际 MIME，并在内存中的只读预览标签打开；SVG 还会经过单独清洗。
- **异常出版物防护**：压缩条目数量、解压体积、单条目大小与压缩比均有限制，同时拒绝危险路径、加密条目、XML Entity / DOCTYPE 及不受支持的压缩方式。

这套流程的目标不是像素级复刻每一本 EPUB，而是将来源复杂的出版物转换为**安全、清晰且适合编辑器环境的语义内容**。

### 沉浸阅读

沉浸阅读让正文自然出现在代码旁边：从书架启动后，聚焦任意文本编辑器，当前页便会从光标所在行开始，附着在该行及后续代码行的末尾。

它基于 VS Code Decoration 实现，因此：

- 不会插入、修改或保存用户文档。
- 切换编辑器或移动光标时，只重新锚定当前页，不会误推进阅读进度。
- 文本按 Unicode 字形簇分页，不会拆开 Emoji、组合字符或代理对。
- 光标下方代码行不足时，只推进实际成功显示的内容。
- 常规 Reader 与沉浸阅读共享同一份阅读位置，切换模式后可以自然续读。
- 任意时刻只保留一个活动书籍会话，切书、切模式与停止阅读都会先保存页首，再释放旧会话。

沉浸阅读支持独立设置：每页视觉行数、每行最大字形簇数、文字与背景颜色、字重、斜体和左侧间距均可调整。默认使用 `Alt+Shift+Q` 结束当前沉浸阅读。

## 打字练习

**MoyuPlus Typing** 位于 Activity Bar，并使用独立 Webview 提供完整的练习流程。素材可以来自：

- 导入的 TXT；
- 导入 EPUB 后选择的章节；
- Reader 书架中的 TXT 或 EPUB；
- 临时粘贴的任意文本。

### 可配置的练习计划

- 练习范围：整份素材、文章、章节或合法选择范围。
- 结束方式：练完整个范围、限时、定长或手动结束。
- 错误策略：必须修正，或允许跳过错误继续输入。
- 文本规则：大小写、标点等价与空白处理。
- 推进方式：自动推进或按 Enter 推进，连续显示或逐行显示。
- 练习界面：字号、行高、字体、局内指标、空白符与虚拟键盘。

### 为真实输入设计

练习面板直接处理浏览器原生输入与 composition 事件：

- 中文输入法的拼音预编辑和候选切换不会推进练习。
- 确认候选后，最终文本只提交一次。
- 普通键入、粘贴、语音输入和词组提交按 Unicode 字素统一判定。
- Backspace、Delete、Undo、Redo、Enter 与 Tab 均由练习面板内的可见输入框处理，不接管普通编辑器按键。

练习过程中会实时更新速度、准确率、持续时间和目标剩余；完成后生成不可变结果，并据此投影历史、每日统计与错词强化列表。强化模式会将历史错词分批组织为新的训练队列，直到稳定通过。

## 隐私与安全

MoyuPlus 默认遵循以下边界：

- 书籍始终从用户选择的本地文件读取，不上传、不联网。
- EPUB 正文只在内存中解压、清洗和显示，不持久化正文副本。
- Reader 与图片预览使用严格 CSP，禁止网络连接、外部脚本、Frame 与媒体加载。
- EPUB 中的脚本、表单、外部资源和危险链接会被移除或拒绝。
- 图片资源按需读取，不会写入工作区或长期解压目录。
- 阅读进度只保存结构化位置，不保存正文或文本引用。
- 打字练习数据保存在扩展专用存储中，不修改工作区文档。

> 打字模块导入的练习素材会由 MoyuPlus 保存为内部副本，以支持恢复与历史练习；移除素材后有 10 秒撤销期，期满会删除内部正文副本，但不会删除用户的原始文件或既有成绩。

## 快速开始

### 安装 VSIX

项目根目录提供了已构建的 VSIX。可在 VS Code 中打开扩展视图，选择 **Views and More Actions → Install from VSIX...**，然后选择对应文件；也可以使用命令行：

```bash
code --install-extension ./moyuplus-0.3.1.vsix
```

MoyuPlus 要求 VS Code `1.92.0` 或更高版本。

### 开始阅读

1. 在资源管理器中展开 **MoyuPlus Reader**。
2. 点击“导入”，选择本地 TXT 或 EPUB。
3. 在书架中选择“阅读”进入侧边栏分页，或选择“沉浸阅读”。
4. 启动沉浸阅读后，将焦点移回文本编辑器即可显示正文。

### 开始练习

1. 打开 Activity Bar 中的 **MoyuPlus Typing**。
2. 导入素材、从 Reader 书架选择内容，或粘贴临时文本。
3. 选择练习范围并配置本次计划。
4. 点击“保存并开始练习”，在独立面板中输入。

## 快捷键

| 功能 | 默认快捷键 | 说明 |
| --- | --- | --- |
| Reader / Git Log 切换 | `Alt+Q` | 在 Reader 与当前仓库的 Git Log Reader 间切换 |
| 停止沉浸阅读 | `Alt+Shift+Q` | 仅在沉浸阅读活动时生效 |
| 上一页 / 下一页 | 未绑定 | 可在 VS Code Keyboard Shortcuts 中自定义 |
| 上一章 / 下一章 | 未绑定 | 可在 VS Code Keyboard Shortcuts 中自定义 |
| 撤回阅读位置 | 未绑定 | 可在 VS Code Keyboard Shortcuts 中自定义 |

非正文状态触发阅读命令时，MoyuPlus 会保持静默，不会意外打开或抢占阅读器焦点。

## 附加能力：Git Log Reader

除两项核心模块外，MoyuPlus 还可以将当前 Git 仓库的提交记录作为分页内容阅读。按 `Alt+Q` 进入后，会读取当前仓库与分支；再次打开时优先显示本次扩展运行期间的内存缓存，并在后台刷新。返回 Reader 后，原书与阅读位置会被恢复。

## 已知限制

- 不支持 DRM、加密 EPUB、音视频内容与依赖脚本的交互式出版物。
- Reader 采用统一语义排版，不保留原书字体、颜色、字号、边距、多栏、浮动或固定版式。
- 复杂版式 EPUB 会退化为可读内容，不承诺像素级还原。
- 纯图片 EPUB 不提供 OCR；用于打字练习前需要先获得可读取的文本。
- 当前不提供在线练习来源。
- 阅读位置撤回历史仅存在于当前 Reader Webview 会话，不跨重载或重启持久化。

## 本地开发

```bash
npm install
npm run compile
npm test
```

常用命令：

| 命令 | 用途 |
| --- | --- |
| `npm run compile` | TypeScript 类型检查并构建扩展与 Webview |
| `npm run test:unit` | 运行 Vitest 单元测试 |
| `npm run test:layout` | 运行 Playwright 布局测试 |
| `npm run test:extension-host` | 构建并运行 Extension Host 测试 |
| `npm run package` | 编译、测试并生成 VSIX |

核心代码分布：

```text
src/
├─ adapters/epub/    # EPUB 容器、Package、正文与图片安全处理
├─ adapters/txt/     # TXT 解码、分章与定位
├─ reader/           # 阅读会话、Webview、沉浸展示与导航
├─ domain/           # 书籍、Locator、分页与阅读偏好
├─ typing/           # 打字练习领域、应用层、存储与内容来源
└─ webview/          # Reader、Typing 与设置界面
```

版本变化见 [CHANGELOG.md](CHANGELOG.md)。
