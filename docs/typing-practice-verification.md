# MoyuPlus 打字练习验收

## 自动验证范围

自动测试覆盖：

- DOM `compositionstart`、`compositionupdate`、`compositionend` 和尾随 `input` 去重。
- direct、composition、paste、block/correct、单 in-flight FIFO 和迟到消息。
- Host 事务幂等、revision 冲突、日志校验、崩溃重放、压缩和完成去重。
- 关闭/恢复、租约竞争、20 万字素有界投影和 50 ms p95 性能门槛。
- 真实 Chromium 的可见输入、组合事件模拟、焦点、窄窗口和主题布局。
- 真实 VS Code WebviewPanel 的创建、ready 握手，以及不打开练习 TextDocument。

浏览器事件模拟只验证产品协议与状态机，不能替代真实 Windows 输入法验收。

## Windows 微软拼音人工矩阵

执行前记录 VS Code、Windows、微软拼音版本、主题、日期和测试人。使用自由粘贴素材：

```text
abc主题检查：错误修正
```

错误处理选择“必须修正”，然后开始练习。

1. 关闭中文输入法，输入 `abc`。三个字符都应立即正确，进度为 3。
2. 开启微软拼音，键入 `zhu`，多次切换候选并停留。拼音只在输入框的预编辑区域可见；进度不动，不显示错误，不关闭面板。
3. 确认“主”。只推进一个字，下一目标立即变成“题”。
4. 使用单字候选完成一次“主题”；重新开始后再用词组候选一次提交“主题”。两种方式都只按最终两个字推进。
5. 再次键入拼音并按 Esc 取消。取消不得产生练习输入。
6. 故意输入 `X`。只有错误输入可见并标错，进度停住；按 Backspace 后恢复输入。
7. 完成剩余文本，并检查快速英文、粘贴和中英文切换都按顺序处理。
8. 输入未完成时切换标签，再关闭面板。从 Typing View 返回当前练习；revision 和进度必须保持，待处理文本不得重复。
9. 完成后尝试返回旧面板或触发迟到输入。不得新增进度或重复 Result。
10. 检查 Extension Host 控制台：不得出现未处理 Promise、save 错误、dirty/rollback 错误或自动退出。
