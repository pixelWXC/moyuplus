# MoyuPlus 打字练习设置

## 输入方式

练习在独立的 **MoyuPlus 打字练习** Webview 面板中进行。面板中的可见文本输入框直接接收浏览器产生的文本和输入法组合事件：

- 普通键入按已提交文本判定。
- 中文输入法的拼音和候选切换停留在预编辑状态，不推进练习。
- 确认候选后，最终文本只提交一次。
- 粘贴、语音输入和一次提交的词组会按 Unicode 字素顺序判定。

输入法组合状态来自浏览器事件，不是练习策略，因此设置页不提供输入方式选择。

## 当前练习计划

Typing 设置页可以配置：

- 本次练习范围：整份素材、文章、章节或合法选择范围。
- 结束方式：练完本次范围、达到指定时间、达到指定单元数或手动结束（自由练习）。只有限时和定长模式会显示对应的数值设置；自由练习不设时间和单元数限制。
- 错误处理：必须修正或允许跳错。
- 文本规则：中英文标点等价、空白处理和大小写。
- 推进与显示：自动或 Enter 推进、连续或逐行呈现、练习窗口局内指标和空白符。
- 界面与键盘：练习字号、行高、编辑器/界面字体以及是否显示虚拟键盘。虚拟键盘固定使用左右手区域配色，不提供单独开关。

限时模式由扩展进程按活动练习时长执行；暂停期间不计时，到点后会自动结束并按“限时结束”保存结果。练习过程中，当前速度、准确率、练习时长和目标剩余只在练习窗口更新；结束后完整结果同步到侧栏。

“设为默认”保存判定、文本、推进、显示、界面和键盘偏好；素材、本次练习范围和结束方式不会写入全局默认。点击“保存并开始练习”时，界面和键盘偏好也会写入打字模块自己的配置，供随后打开的练习窗口使用。

## 面板外观与快捷键

练习面板使用 VS Code 主题令牌，跟随浅色、深色和高对比度主题；具体字号、行高和字体来源可在 Typing 的“本次设置”页调整。配置保存在 MoyuPlus 插件存储中，不依赖 VS Code 扩展设置。它不会创建自定义语言、虚拟文本文件或工作区文件。

可见输入框处理 Backspace、Delete、Enter、Tab、Undo 和 Redo。普通编辑器中的快捷键行为不受影响，也不会注册全局 Inline Completion。

## 持久化与恢复

- Snapshot、Checkpoint、事务日志和 Result 保存在扩展专用存储目录。
- 每次输入事务带有稳定 ID 和基础 revision；重复消息不会重复推进。
- 日志先持久化再更新内存权威状态。关闭面板或窗口后恢复时，从 Checkpoint 加连续日志重放。
- 同一 workspace 只允许一个租约持有者写活动 Session。
- 不修改或保存工作区文档，因此不会产生 dirty 标记、保存提示或回滚写入。

## 兼容性

旧偏好、Snapshot 和 Checkpoint 中的输入模式字段只在迁移读取时接受，不参与新判定，也不会再次写出。旧物理行会话只生成一次安全提示，不伪造新版成绩。
